Attention-Based CNN Architecture

Technical Overview of the MobileNetV2 + CBAM Model

System Overview

This B.Tech Major Project implements an Attention-Based Convolutional Neural Network (CNN) for plant leaf disease classification from digital images. The proposed model combines a lightweight MobileNetV2 backbone with a Convolutional Block Attention Module (CBAM) to refine extracted feature representations before final classification.

The model is trained to classify plant leaf images into 38 different classes, including healthy and diseased plant categories.

Model Architecture

1

Input Image

Plant leaf images are resized and preprocessed before being passed to the neural network.

2

MobileNetV2 Feature Extraction

MobileNetV2 acts as the convolutional backbone and extracts hierarchical visual features from the input image. Its lightweight architecture makes it suitable for efficient image classification.

3

CBAM Attention Module

The extracted feature maps are refined using the Convolutional Block Attention Module (CBAM), which sequentially applies Channel Attention and Spatial Attention.

4

Global Average Pooling

The attention-refined feature maps are reduced into a compact feature representation.

5

Dropout

Dropout is applied to reduce overfitting and improve the model's generalization capability.

6

Dense Classification Layer

The final Dense layer produces probability scores for all 38 plant disease and healthy classes.

CBAM Attention Architecture

CBAM sequentially applies Channel Attention followed by Spatial Attention.

1

Input Feature Tensor \(\mathbf{F} \in \mathbb{R}^{H \times W \times C}\)

Feature maps extracted by the MobileNetV2 convolutional backbone.

2

Channel Attention Module \(\mathbf{M}_c(\mathbf{F})\)

Channel attention aggregates spatial information using Global Average Pooling and Global Max Pooling. These features are processed through a shared MLP with reduction ratio \(r = 8\).

\[ \mathbf{M}_c(\mathbf{F}) = \sigma \left( \text{MLP}(\text{AvgPool}(\mathbf{F})) + \text{MLP}(\text{MaxPool}(\mathbf{F})) \right) \]

The channel-refined feature map is:

\[ \mathbf{F}' = \mathbf{M}_c(\mathbf{F}) \otimes \mathbf{F} \]
3

Spatial Attention Module \(\mathbf{M}_s(\mathbf{F}')\)

Spatial attention computes average pooling and maximum pooling across the channel dimension. The resulting feature maps are concatenated and processed using a \(7 \times 7\) convolution.

\[ \mathbf{M}_s(\mathbf{F}') = \sigma \left( f^{7 \times 7} \left( [ \text{AvgPool}(\mathbf{F}'); \text{MaxPool}(\mathbf{F}') ] \right) \right) \]

The final attention-refined feature map is:

\[ \mathbf{F}'' = \mathbf{M}_s(\mathbf{F}') \otimes \mathbf{F}' \]
